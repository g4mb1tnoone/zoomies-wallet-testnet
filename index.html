Separate test environment

Wallet testing for Zoomies

This site hosts the public files used by the local Zoomies wallet integration. The game, account data and payment verification continue to run on the developer's computer.

Testnet only for payments. Zoomies Test GRAM (zGRAM-TEST) has no monetary value and is separate from the real GRAM cryptocurrency. Test credits cannot be withdrawn or spent in the live game.

  • TON Connect manifest identifies the test application to the wallet.
  • Test-token metadata identifies the non-monetary test token.
  • Mainnet collection verification in the local game is read-only.

Open the wallet panel in your locally running Zoomies game to connect. This static site has no payment form or wallet-signing code.

No private keys, recovery phrases, user accounts or game source are hosted here. This page uses no analytics or application cookies; GitHub Pages handles hosting requests.
